# 🧹 SimpleCleaner

A lightweight, portable, and multi-language desktop utility built with Python and CustomTkinter designed to clean temporary system files and custom directories securely.

---

## ✨ Features

- **Multi-Language Support**: Fully translated into English (EN), Portuguese (PT), Spanish (ES), French (FR), Russian (RU), and Arabic (AR).
- **Fixed System Paths**: Quick cleaning for Windows Temp, User Temp, and Prefetch directories.
- **Custom Paths Manager**: Add, manage, and clean up to 3 extra custom folders directly from the settings panel.
- **Automated Scheduling**: Run cleanups automatically on a fixed daily time or at regular hourly intervals in the background.
- **Tray/Taskbar Behavior**: Option to minimize to the taskbar instead of closing outright.
- **Sleek Dark UI**: Modern astronomy/space-themed custom aesthetic without external image dependencies.

---

## 🚀 Installation & Usage

1. Download the latest installer from the [Releases page](https://github.com/Nathan1290/SimpleCleaner).
2. Run the installer and follow the setup wizard.
3. Launch **SimpleCleaner** from your desktop or Start Menu.
